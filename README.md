# Lokomoto Centar — landing stranica

Statički sajt za GitHub Pages.

## Fajlovi
- `index.html` — cela stranica u jednom fajlu (runtime, slike, fontovi i logo su ugrađeni)
- `.nojekyll` — neka ostane u repozitorijumu

## Hostovanje
1. Ubaci `index.html` i `.nojekyll` u koren repozitorijuma.
2. Settings → Pages → Deploy from a branch → `main` / `/(root)`.
3. Sajt je na `https://<korisnik>.github.io/<repo>/`.

Sve je ugrađeno u `index.html`, pa radi i lokalno (dupli klik) i na hostingu.
Za Google mapu je potreban internet.
